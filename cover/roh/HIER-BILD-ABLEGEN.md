# Coverbild hier ablegen

Das fertige Bild **ohne Text** kommt in diesen Ordner. Danach:

    python3 scripts/coverbau.py --bild cover/roh/<datei> --autor "<Name>"

Ohne Git geht das über github.com: Branch auswählen,
**Add file → Upload files**, Bild hineinziehen, Pfad auf `cover/roh/`
setzen, **Commit changes**.

Der Prompt für das Bild steht in `../../COVER.md`, Abschnitt
„Prompt für das Bild".
